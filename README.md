# prachiti.exe 🍒

Personal portfolio of **Prachiti Palande**, AI & Data Science · M.Sc. Computer Science @ University College Dublin.

The look is candy-cart × Y2K desktop × pixel game: scalloped candy headers on grid paper, draggable retro windows, a pixel-art "player" and a start screen.

## Features
- 🎮 Boot / "press START" screen with an animated starfield and a walking pixel avatar
- 🪟 Draggable Y2K windows (they refuse to close 😌)
- ✦ Sparkle cursor trail, parallax stickers, marquees and typing text
- 🪙 Click the stickers to collect coins and unlock an achievement
- 📜 Tabbed Quest Log (experience) with a hand-drawn circle marker
- 📈 XP bar that levels up as you scroll
- ⬆⬆⬇⬇⬅➡⬅➡BA: try it
- Respects `prefers-reduced-motion`, responsive down to phone width

## Run locally
No build step. It's plain HTML/CSS/JS.
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Add your résumé PDF
